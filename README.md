## 🌟 About The Project

SAREGX is a modern, blazing-fast music streaming web application designed with one primary goal: **putting the music first.** 

Tired of audio advertisements interrupting your favorite playlists? SAREGX is built from the ground up to provide a premium, dynamic listening experience with absolutely **zero ads**. 

Built using React and Vite, the platform offers fluid navigation, dynamic theming, and an intuitive user interface that feels right at home on both desktop and mobile devices.

### ✨ Key Features

* 🚫 **100% Ad-Free**: Enjoy your music the way it was meant to be heard—without interruptions.
* ⚡ **Lightning Fast**: Powered by Vite for near-instant load times and buttery smooth UI interactions.
* 🎨 **Beautiful UI/UX**: A modern, sleek interface with dynamic color theming.
* 🔐 **Secure Accounts**: Integrated Google Sign-In and robust authentication powered by Firebase.
* 📱 **Responsive Design**: Flawless playback whether you are at your desk or on the go.

## 🚀 Getting Started

Want to run SAREGX locally? Follow these steps to get your development environment set up.

### Prerequisites

* [Node.js](https://nodejs.org/) (v16 or higher)
* npm or yarn

### Installation

1. **Clone the repository:**
   ```sh
   git clone https://github.com/Astreas-Core/SAREGX.git
   cd SAREGX
   ```

2. **Install dependencies:**
   ```sh
   npm install
   ```

3. **Set up Environment Variables:**
   Create a `.env` file in the root directory and add your Firebase configuration:
   ```env
   VITE_FIREBASE_API_KEY=your_api_key
   VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
   VITE_FIREBASE_PROJECT_ID=your_project_id
   VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
   VITE_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
   VITE_FIREBASE_APP_ID=your_app_id
   VITE_FIREBASE_MEASUREMENT_ID=your_measurement_id
   ```

4. **Start the development server:**
   ```sh
   npm run dev
   ```

5. **Open your browser:**
   Navigate to `http://localhost:5173` to see the app in action!
